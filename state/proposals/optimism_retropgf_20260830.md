# Optimism RetroPGF Round 5 Proposal

## Project Name
Autonomous Agent Security Infrastructure

## Description
We built autonomous smart contract auditing agents using Claude Fable 5 orchestration to enhance the security of the Optimism ecosystem and the broader Superchain. Our system automates the discovery of complex vulnerabilities, with a demonstrated capability in the LayerZero V2 vulnerability triage pipeline. By leveraging advanced AI orchestration, we have created a scalable, open-source security infrastructure that significantly reduces the time and cost associated with manual smart contract audits. All of our tooling is open-source and available to the public.

## Impact Statement
Our infrastructure has delivered measurable value to the ecosystem by automating the discovery of cross-chain messaging vulnerabilities that protect over $4B+ in Total Value Locked (TVL). By providing a robust, automated auditing pipeline, we have increased the security posture of critical cross-chain protocols operating within the Optimism and Superchain environments. This proactive security approach prevents potential exploits, safeguarding user funds and ensuring the long-term sustainability and trust in the ecosystem's public goods.
